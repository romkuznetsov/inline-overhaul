# Исключения к З3: адрес каждого

**Что это.** З3 запрещает править движки; заказчик разрешает исключения по
одному. Здесь **адрес** каждого: номер, дата, файл и одна строка о том, что
разрешено.

**Когда открывать.** Собираетесь править файл под З3 — то есть `src/pkm_v2/**`,
`src/navigation_runtime.js`, `src/pkm_runtime_v2.js`, `src/core/pkm_*`, 
`src/core/status_*`, `token_graph_unified.js`, `line_pipeline.js`. 
Пути движков переехали в `src/` 2026-09-19 (исключение № 131); сами файлы при
этом не менялись. 
Запрет, разрешения и рамка к ним живут в `CLAUDE.md`, раздел «Что не трогать»;
этот файл целиком каждую сессию не читается.

**История каждого — разрешение, все места, цена и чем закреплено — в PRD 3.3**,
разбор поведения — в 10.13.*. Файлы здесь названы своим именем без папки;
полные пути — в PRD 3.3 и в самом запрете.

**Сколько их сегодня, говорит прогон, а не эта строка** (У-145):
`node tests/regression/z3_exceptions_split_tests.js`. Он же сверяет таблицу с

исключение, которого не видно перед первой правкой.
