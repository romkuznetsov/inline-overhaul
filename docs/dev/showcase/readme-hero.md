# readme-hero — GIF в шапке README

**Состояние: сценарий, черновик. Не прогнан на стенде, субтитры не окончательные.**

Его слово 2026-09-29 (ответ интервью о снимке README): «я думаю вообще нужно
будет использовать не картинку, а gif, где есть исходная строка и пользователь
вызывает tagwheel и за 5 секунд настраивает все values». До записи в шапке стоит
снимок строки (`docs/media/readme/line-{light,dark}.png`, стенд
`node tools/obsidian_bench.js clean-readme-shot`).

## Что показывается

Чистый vault, стартовый набор, тема Obsidian по умолчанию — то, что увидит новый
человек. Длина — около пяти секунд действия плюс секунда на готовую строку.

| # | Что на экране | Клавиша (плашка) | Субтитр (черновик) |
|---|---|---|---|
| 1 | строка `- call the bank`, каретка в конце | — | `A plain line` |
| 2 | открывается tagWheel слева | хоткей `tagWheel Left` | `tagWheel opens over the line` |
| 3 | `Status` → `#todo` | `↑` | `Pick a status…` |
| 4 | `Priority` → `#high` | `→` `↑` | `…a priority` |
| 5 | строка записана | `Enter` | — |
| 6 | tagWheel справа: `Project` → `[[Project A]]`, `Due` → дата | хоткей `tagWheel Right`, стрелки, `Enter` | `…a project and a due date` |
| 7 | готовая строка, как на снимке шапки | — | `Plain markdown in the file` |

Итог обязан совпасть со строкой в блоке `markdown` README:
`- [ ] #todo #high || call the bank || [[Project A]] 📅2026-09-15` — дата в записи
будет сегодняшней, и строку README тогда правят под неё.

## Что проверить на стенде до субтитров

- порядок Fields в tagWheel стартового набора и число нажатий до каждого Value;
- ставит ли чекбокс сам `#todo` (Prefix behavior) или его нужно показывать;
- как `Due` получает дату в tagWheel — Value или команда `Due next`.
