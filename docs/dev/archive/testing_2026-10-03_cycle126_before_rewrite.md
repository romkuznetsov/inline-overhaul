## 1. Command Field: пустое значение снимает коллаут
- [x] #done :: принято
- 💬

> [!question]- Описание задачи
> Ваше `💬`: «дефолтное состояние означает отсутствие выбора пресета = отсутствие коллаута — это универсальное правило». Теперь в tagWheel пустое значение (`-` в ячейке пресетов или пустая категория) значит «коллаута нет»: если курсор в коллауте, `Enter` снимает его, вне коллаута — ничего не создаёт. Категория с одним пресетом по-прежнему применяет его выбором категории. Хоткеи `next` / `previous` работают как прежде. Подробно — отчёт `430у`.
