# Знак, палитра, картинки

У плагина два знака: **словесный** — основной, и **пиктограмма** — для квадратных мест.
Везде, где есть строка места, ставится словесный.

## Словесный знак

```
#inline[[Overhaul]]▌
```

Знак читается как строка в редакторе: `#in` — тег в пузырьке, `line` — обычный текст,
`[[Overhaul]]` — ссылка, за ней курсор. Это не украшение: плагин ровно этим и
занимается — держит тег, ссылку и дату в одной строке с мыслью.

### Файлы

Все в `docs/brand/`. **Перерисовывать, перекрашивать и менять пропорции нельзя** —
брать готовый файл.

| Файл | Где |
|---|---|
| `io-wordmark-light-anim.svg` | шапка README, светлая тема. Каретка мигает |
| `io-wordmark-dark-anim.svg` | то же, тёмная тема |
| `io-wordmark-light.svg` | статика для светлого: там, где анимация неуместна |
| `io-wordmark-dark.svg` | статика для тёмного |
| `io-wordmark-light.png`, `io-wordmark-dark.png` | 1030×136, там где SVG не поддерживается |
| `social-preview.png` | 1280×640, **Settings → General → Social preview** |

### Подключение

Фон у знака прозрачный, поэтому нужны обе темы:

```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="docs/brand/io-wordmark-dark-anim.svg">
  <img alt="inlineOverhaul" src="docs/brand/io-wordmark-light-anim.svg" width="560">
</picture>
```

Ширина задаётся явно. Без неё знак растянется на всю колонку и станет крупнее
заголовка.

> [!NOTE]
> Анимация внутри SVG работает, когда файл подключён через `<img>`: браузер выполняет
> CSS и SMIL, но не скрипты. Встроить `<svg>` прямо в Markdown нельзя — GitHub его
> вырезает. Поведение проверено практикой, а не документировано GitHub, поэтому после
> первой публикации **посмотри на живую страницу**: если каретка не мигает, поставь
> статические файлы и не трать на это время.

### Свободное поле

Вокруг знака — высота пузырька `#in` со всех сторон. В это поле ничего не заходит.

### Минимальный размер

**360 px по ширине.** Ниже каретка и скобки схлопываются. В узких и квадратных местах
ставится пиктограмма.

## Пиктограмма

```
[[#iO]]
```

Короткое имя внутри wikilink, `#` делает его тегом. Та же грамматика, что у словесного
знака, только в квадрате.

| Файл | Где |
|---|---|
| `io-mark-light.svg` | светлый фон |
| `io-mark-dark.svg` | тёмный фон |
| `io-mark-{light,dark}-{512,256,128,64,32}.png` | там, где SVG не поддерживается |

**Пиктограмма — не замена словесному знаку, а дополнение.** Она ставится только там,
где нужен квадрат и нельзя показать название: фавикон, карточка плагина, аватар. В
шапке README, в баннерах и в социальном превью — словесный.

Цвета внутри: `#` янтарный, `iO` — `#35617d` на светлом и `#7fb6db` на тёмном, скобки
того же цвета, смешанного с плиткой пополам.

> [!NOTE]
> **Ниже 24 px пиктограмма не читается.** Семь знаков в квадрате — это меньше двух
> пикселей на штрих. Экспорт в 32 px — самый мелкий честный размер; для настоящего
> 16-пиксельного фавикона нужен другой рисунок, и его нет.

## Палитра

| Токен | Значение | Что означает |
|---|---|---|
| `amber` | `#ffb547` | тег. Единственный тёплый цвет |
| `tag-ink` | `#3a2400` | текст внутри янтарного тега |
| `link` | `#4a7b9b` | wikilink на светлом |
| `link-dark` | `#6ba8d6` | wikilink на тёмном |
| `caret` | `#cb06c4` | каретка ввода |
| `ink` | `#111111` | обычный текст на светлом |
| `cream` | `#f7f4ff` | обычный текст на тёмном |
| `night` | `#141221` | тёмная подложка: баннеры, превью |
| `night-soft` | `#1d1b30` | подложка бейджа, карточка кода |
| `mark-io` | `#35617d` | `iO` в пиктограмме, на светлом |
| `mark-io-dark` | `#7fb6db` | то же, на тёмном |

Стальной и пурпурный сняты пипеткой со скриншота Obsidian: так выглядят ссылка и
курсор в редакторе. Это и есть связь с Obsidian — не логотип и не фиолетовая плашка.

**Скобки — не отдельный цвет.** Это `link`, смешанный с фоном: 55 % к белому на
светлом, 45 % к `night` на тёмном. Так же Obsidian показывает разметку — тусклее
содержимого.

### Два правила про цвет

1. **Янтарь встречается один раз на изображение.** Он отмечает ровно одну вещь: тег
   в знаке, одну выделенную строку, одно значение в примере. Два янтарных акцента
   рядом гасят друг друга.
2. **Янтарь задаётся цветом, а не прозрачностью.** Полупрозрачный `#ffb547` поверх
   тёмного уходит в розовый и начинает спорить с кареткой.

## Бейджи

Один стиль на все: `style=flat-square`, подложка `1d1b30`, основной цвет `4a7b9b`,
янтарь `ffb547` — только для бейджа, на который надо смотреть.

```
https://img.shields.io/badge/Obsidian-1.13%2B-4a7b9b?style=flat-square&labelColor=1d1b30
https://img.shields.io/github/v/release/romkuznetsov/inline-overhaul?style=flat-square&labelColor=1d1b30&color=4a7b9b
https://img.shields.io/badge/status-public%20beta-ffb547?style=flat-square&labelColor=1d1b30
https://img.shields.io/github/license/romkuznetsov/inline-overhaul?style=flat-square&labelColor=1d1b30&color=4a7b9b
```

Не больше четырёх в строку. Разноцветных бейджей по умолчанию — зелёный, синий,
оранжевый вперемешку — быть не должно.

## Гифки

Правила для README — в [`readme.md`](readme.md). Общее для всех документов:

- ширина задаётся явно, `alt` обязателен;
- подпись говорит, что происходит, а не как называется команда;
- запись начинается с состояния покоя и заканчивается им же — иначе цикл дёргает;
- в README только записи с настоящим Obsidian; схемы живут в `docs/showcase.md`.

## Социальное превью

`docs/brand/social-preview.png` — 1280×640, меньше мегабайта. Ставится руками:
**Settings → General → Social preview → Upload an image**. Без него ссылка на
репозиторий выглядит серой карточкой GitHub везде, где её кинут.

Пересобирать при смене названия, описания или знака. Больше — незачем.
