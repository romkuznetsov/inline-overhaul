### 146у. Строка-заголовок теряла значение поля — **сделано 2026-09-14, вечер**

**Замечания от вас не было — нашёл обходом**, и вы выбрали чинить это раньше
уборки кода.

**Что было.** На строке-заголовке шаг по Importance **уносил** значение:
`## #/1 :: текст` превращалось в `## текст`, и так же с `#/2`. На строке списка
и на цитате то же поле переключается верно, и шаг по другому полю на том же
заголовке — тоже.

**И уносило не только значение.** Строка с двумя зонами схлопывалась целиком:
`## #/1 #todo :: текст :: 📅2026-09-14 10:00` превращалась в
`## #todo текст 📅2026-09-14 10:00` — оба разделителя исчезали, зоны строки
пропадали.

**Чем это оказалось.** В коде стояла пересборка строки-заголовка, срабатывавшая
на **каждом** шаге по Importance, а не в конце цикла: строка собиралась заново
из исходной, с вычеркнутыми значениями и вычеркнутыми разделителями.
Разделители там к тому же стояли готовыми (`||`, `::`, `~~`), а у вас они свои.
Объяснения у этой пересборки не было ни одного — она пришла первым же релизом и
ни разу не названа ни в одном документе; решило поведение соседей: на списке, на
цитате и у другого поля на том же заголовке значение циклится.

**Как проверить, за минуту:** строка `## текст`, нажать шаг по Importance
**дважды**. Значение должно смениться со `#/1` на `#/2`, а не исчезнуть. И
вторая строка — `## #/1 #todo :: текст`: разделитель и чужое значение обязаны
остаться на месте.

**Чем закреплено.** Проверка спрашивает оба признака сразу — значение сменилось
и зоны строки целы, — с контролем «на строке списка то же поле и правда
циклится». Подмена, возвращающая пересборку, краснеет. Семь шагов из семи
зелёные. Разбор — PRD 10.13.119.

### 145у. Начало строки: скобки без дефиса и строка-цитата — **сделано 2026-09-14, вечер**

**Исполнены два ваших решения того же дня** — и оба они про одно: что на строке
принадлежит Obsidian, а что вам.

**Скобки без знака списка (В-114).** Ваше слово: «как в Obsidian: это ваш
текст». Было: `[ ] текст` после шага по полю давала `- #/1 [ ] :: текст` —

`- #/1 :: [ ] текст` — скобки остались вашим словом и стоят там, где вы их
написали. Задачей строка становится только со знаком списка, как в Obsidian.

* `> текст` → `> #/1 :: текст` — цитата осталась цитатой, нашего знака списка

* `> [!note] важное` → `> [!note] #/1 :: важное` — каллаут пережил действие;
* `> - текст` → `> - #/1 :: текст` — знак списка, который поставили вы, остался

* `> > текст` → `> > #/1 :: текст` — вложенная цитата тоже.

**Чем это оказалось.** «Где начинается строка» плагин считал в пяти местах

заход, и он остаётся в очереди.

**Найдено по дороге и не чинилось:** на строке-заголовке второй шаг по полю

строке-цитате то же поле циклится верно. Дефект старше этой правки и не из

### 144у. Подложка на перенесённой строке: оба ваших бага — **сделано 2026-09-14, вечер**

**Ваши слова по строке `S37`:** «иногда полоска по прежнему рисуется до границ

**Чем это оказалось.** О том, где кончается зрительная строка, плагин спрашивал

сделано для строки-заголовка.

**Цена названа вслух:** на самом верху ползунка высоты подложки два ряда **одной
