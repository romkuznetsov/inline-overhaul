# Inline Overhaul Showcase

Lightweight GIFs captured from a real Obsidian desktop session. Hotkeys shown below are examples from the demo vault and remain fully configurable in Obsidian.

## Move lines

Move the current line up or down without cutting and pasting.

Demo hotkeys: `Ctrl+Shift+Down`, then `Ctrl+Shift+Up`.

![Move lines in Obsidian](media/showcase/move-lines.gif)

## Cycle line prefixes

Move Left/Right can cycle structural prefixes. Repeated presses move through the configured prefix list; cycle-end behavior can wrap or fall back to indentation.

Demo hotkeys: `Ctrl+Shift+Right` and `Ctrl+Shift+Left`.

![Cycle line prefixes in Obsidian](media/showcase/prefix-cycle.gif)

## Cycle a PKM field

Each configured field receives increase/decrease commands. This example cycles the importance field through its configured values, then removes it at cycle end.

Demo hotkey: `Alt+Up`.

![Cycle a PKM field in Obsidian](media/showcase/pkm-cycle.gif)

## TagWheel

TagWheel exposes configured fields and values directly beside the active line. Arrow keys navigate fields and values; `Enter` applies and `Escape` cancels.

Demo: open with `Alt+Down`, navigate with arrow keys, cancel with `Escape`.

![Use TagWheel in Obsidian](media/showcase/tagwheel.gif)

## More workflows

Inline Overhaul also includes:

- enhanced `Ctrl+A` selection scopes: line → indentation tree → note;
- header and inline-zone navigation;
- Binder text commands and Smart bracket cycling;
- configurable tag bubbles, hierarchy strips, separator colors, and TagWheel scroller;
- config Generate/Apply for portable PKM setups;
- opt-in Inline2Note Transform with templates, YAML mapping, source cleanup, collision policies, and parent/child handling.

See the [complete setup and feature guide](instructions.md) for configuration, copyable examples, safety notes, and current beta limitations.
