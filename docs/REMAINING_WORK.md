### Н4. Разбор: ссылка на новую заметку в заметках, на которые ссылается строка

**Где живёт поведение.** `src/features/transform_feature.js`, конец
`runInline2Note`: заметка уже создана (`writeInline2Note`), исходная строка уже
переписана. Новая работа встаёт **после** этого и до открытия заметки.

**Что уже готово и переиспользуется целиком.** Машинерия «вставить блок в
существующую заметку по месту» у нас есть и работает — её зовёт режим
`Add to note`: `appendBlockIntoNote`, `placeBlockUnderHeader`,
`parseTargetHeaderSpec`, `headerLineForSpec`, `composeBodyWithPlacement`. Его
слова «возможно, дублировать контролы как у note-content» — это ровно они, и
дублировать тела не придётся: у них уже есть форма «куда именно вставить»
(`placement`), и она читается из одного места (`resolvePlacementSource`).

**Что новое.** Три куска:

  1. *кого править* — значения типа link в Block исходной строки. Их называет
     тот же разбор, которым Transform читает строку (`buildTransformContext`,
     после правки 10.13.177 он видит значение в любом Block). Цель ссылки
     разворачивает общий дом `unwrapWikilinkToken`;
  2. *чем править* — текст вставки: ссылка на новую заметку. Форма ссылки —
     общий дом (`WIKILINK_TOKEN_SRC`), путь — тот же, что уже кладётся в
     исходную строку (`deriveSourceWikilinkFromTargetPath`);
  3. *не дублировать* — «но не дублировалась, если ссылка уже есть». Признак
     «в заметке уже есть ссылка на этот путь» обязан быть **одним**
     объявлением: его же спросит и проверка.

**Цена в панели.** Новая группа на вкладке Transform: тумблер плюс шесть строк,
показывающихся при `On`. Это прототип → `npm run gen:schema` → каталог текстов →
гейты Г10, Г17–Г19, Г24, Г25. Строк в группе семь — предела в двенадцать не
задевают.

**Чем закреплять.** Сборка текста вставки — обычной проверкой на настоящих
функциях; запись в чужую заметку — подделкой vault того же рода, что уже стоит
в `transform_runtime_tests.js`; «не дублируется» — прогоном дважды подряд.

**Его ответы (В-135, 2026-09-17), и работа начинается с них.** Путь ссылки —
**полный**. Заметки-цели нет — **создать пустой и дописать ссылку**. Искать —
**только в Block**, и там же его уточнение: «это должно быть value field=link»,
то есть ссылка, которая и есть значение поля, а не всякая ссылка, стоящая в
зоне значений.

### Н5. Разбор: подсветка места, куда прыгнул курсор

**Где живёт поведение.** Прыжки — `navigation_runtime.js` (`jumpToAdjacentSection`,
`jumpByLineMode`, `navigateInline`), файл под З3. Сама подсветка живёт не там:
рисовать её должен слой редактора, а движку прыжка остаётся сказать «курсор
только что переехал сюда».

**Что уже готово.** Свой слой поверх текста у нас есть и проверен браузером:
`createCaretLayerExtension` в `src/ui/editor/decorations.js` рисует каретку
своей формы (`CARET_LAYER_CLASS`, `caretLayerRangeFor`). Подсветка — такой же
слой, только живущий полсекунды: круг рисуется в координатах каретки и гаснет
анимацией CSS, то есть без единого таймера в коде.

**Что новое.** Три куска:

  1. *сигнал* — «курсор переехал прыжком». Это шов между движком под З3 и
     слоем: чем его передать, решается разбором отдельно (состояние редактора
     `StateEffect` или поле плагина);
  2. *слой* — круг заданного радиуса и цвета, гаснущий за заданное время;
  3. *панель* — пять строк внизу группы `Jumping between headings`: тумблер,
     цвет, скорость затухания, радиус и `Use inside current line`; плюс живой
     предпросмотр с анимацией, как у каретки.

**Цена.** Пять строк панели и предпросмотр — это прототип, генерация схемы,
каталог текстов и гейты; слой — `styles.css` и одно расширение редактора;
сигнал — правка файла под З3, то есть **новое исключение**, и разрешение на
него спрашивается его словом (У-9).

**Чем закреплять.** Браузерный шаг: круг появляется после прыжка, живёт
заданное время и исчезает; при `Off` не появляется вовсе. Это тот самый род
проверки, которым уже держится каретка.

**Его ответы (В-136, 2026-09-17).** Подсветка — **только на прыжках**. Два
прыжка подряд — **гасить прежний круг**. И тем же ответом он добавил третий
контрол, которого в заказе не было: **задержка от 0 до 1 секунды** — «если
пользователь прыгает сразу много, чтобы не возникало раздражение». То есть
строк в панели становится шесть, а не пять, и у задержки свой смысл: круг не
рисуется вовсе, пока прыжки идут чаще неё.
