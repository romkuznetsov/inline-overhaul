## 2. Command Field: очистка строки
- [ ] принято
- 💬 сейчас понял, что не очень удобно если есть всего один subvalue - может, тогда вообще не показывать subfield (т.к. активация parent navigator при единственном subvalue сразу активирует это subvalue). > [!question]- Описание задачи
> Категория `Cleanup` снимает со строки Values всех Fields, кроме отмеченных в пресете. Пресет по умолчанию — `Clear all`. Строка, где снимать нечего, не меняется, а Obsidian говорит об этом уведомлением. Подробно — отчёт `430у`.

> [!action]- Действие

## 4. Command Field в tagWheel
- [ ] принято
- 💬

> [!question]- Описание задачи
> Ваше `💬` к тесту 1: «в tagwheel не появились field=command». Теперь Command Field стоит ячейкой в своём Block, на своём месте среди Fields. Стрелки вверх и вниз на нём выбирают категорию, стрелка вправо переходит в ячейку `preset`, там стрелки выбирают пресет. `Enter` убирает колесо и применяет пресет одной правкой — один шаг `Ctrl+Z`. Выбрана только категория — `Enter` берёт её первый видимый пресет. В строку Command Field не пишется: ни `Enter` на другом Field, ни повтор команды его не записывают. Пока Command Field есть только в Left и Right, в custom block — следующим шагом. Подробно — отчёт `430у`.

> [!example]- Журнал

> [!settings]- Настройки
