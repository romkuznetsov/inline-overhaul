## 5. Keep typed tags in text: Off — тег из фразы переезжает в Block
- [x] принято
- 💬 

> [!question]- Описание задачи
> Ваш заказ: правило тестов 1–4 управляется тумблером в `Placement modes`. Включён (так по умолчанию) — тесты 1–4. Раньше на ваших настройках оно копировалось, а не переезжало: `- #high #todo :: купить #todo молоко`. Разбор — PRD 10.13.286.
